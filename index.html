4-Stage Agent Pipeline

Serial execution chain — each stage feeds the next. Orchestrated by Google Gemini (with DeepSeek fallback).

1

Parse Sources

Multi-source parsing with credibility scoring and conflict detection

2

Extract Insights

Causal chains with dollar-figure impact: cause → effect → $-exposure

3

Plan Actions

Ranked, executable actions with exact API parameters

4

Execute Action

Mock API calls with before/after state snapshot and rollback support

Orchestration Fallback Chain

1

Gemini 2.5-Flash-Lite Primary

Google Gemini native function-calling loop — full agentic orchestration via MCP tools

↓ quota exhausted (429 RPD)
2

DeepSeek Chat Fallback

OpenAI-compatible tool-calling loop — same SSE events, same pipeline

↓ also fails
3

Python Direct Fallback Last Resort

Hardcoded pipeline runs all 4 stages without any LLM orchestration

⚠️ Conflict Detection

When two sources report conflicting values for the same metric (e.g. "delay 3 days" vs "delay 7 days"), the parser picks the higher-credibility source and logs the resolution in parsed.contradictions[]. Age penalty: −0.20 if source is >24h old.

POST /api/analyze — URL auto-fetch (HTML or PDF) 
// Pass a URL as content — backend fetches and strips HTML/extracts PDF
{
  "session_id": "demo-url",
  "sources": [
    {
      "source_id": "web-1",
      "source_type": "news_article",
      "content": "https://example.com/supply-chain-disruption-report"
    }
  ]
}

content_fetcher.resolve_content() detects the URL, fetches it with httpx, strips HTML tags (capped at 12,000 chars), or extracts PDF text via pypdf.

Contract Enforcement

Every agent output is validated before the next stage runs. Failures trigger auto-retry with a correction hint injected into the next prompt.

✅

PASS

Output meets all required fields and value constraints. Pipeline continues immediately.

⚠️

WARN

Output is usable but missing optional fields. Logged and passed through.

❌

REJECT

Output fails critical checks. correction_hint injected into next prompt. Retried up to 3×.
